## Important Data-Entry Rules

- **Academic Year:** Do not edit; marked as required.
- **Sequence Number:** Sequence number `1 .. xxxx`; do not edit. The workbook marks this as optional.
- **Student ID:** Encode as is; refers to the student's ID number.
- **Student name:** Encode last name, given name, and middle name as is. Extension name is optional.
- **Sex:** `0 = Male`, `1 = Female`.
- **Birthdate:** Enter as `yyyy-mm-dd` and format the cell as a date.
- **Complete Program Name:** Should be consistent with the HEI Registry of Programs. The source states that it is automatically input based on HEI and should be similar to the Registry.
- **Year Level:** Numeric, e.g. `1, 2, 3, 4, 5, 6...`.
- **Father's Name:** Last, given, and middle names are optional and should be encoded as is.
- **Mother's Maiden Name:** Last, given, and middle names are required and should be encoded as is.
- **DSWD Household No.:** Encode as is; leave blank if not available.
- **Household Per Capita Income:** Leave blank if not available.
- **Permanent Address:** Encode street and barangay as is, including house number, block and lot where applicable; leave blank if not applicable.
- **ZIP Code:** Encode as is. Put `0` if not available.
- **Disability:** Spell out the disability. The workbook lists the accepted values below. Leave blank if not applicable.
- **Contact Number:** The workbook specifies either an 8-digit telephone number or a 10-digit phone number starting with `9`.
- **Email Address:** Encode as is.
- **Indigenous People Group:** Automatically encode `NO`; otherwise specify the type of IP.
